# Israel Araújo | Portfólio

Site pessoal de Israel Araújo, desenvolvedor web e web designer em Natal/RN.

Página estática em um único `index.html` (CSS e JS embutidos), com imagens em `assets/`.

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```

## Onde editar

- Número do WhatsApp e mensagem pronta: variáveis `WA_NUMBER` e `WA_TEXT` no script do final do `index.html`.
- Cards do anel 3D do topo: lista `SHOTS` no mesmo script. As imagens ficam em `assets/projetos/`.
- Projetos da seção "Sites no ar": bloco `<section id="projetos">`.

## Deploy

Cada push na branch `main` publica automaticamente na Vercel.
